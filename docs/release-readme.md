# WorkState

Windows 电脑活动记录工具，PCState 的后继项目。

[项目主页与完整说明](https://github.com/3plus10i/workstate)

## 使用

需要 Windows 10/11 和 Microsoft Edge WebView2 Runtime。

- 双击 `WorkState.exe` 开始记录；无需安装 Python，也无需附带依赖文件夹。
- 双击托盘图标打开窗口。关闭窗口后继续记录，从托盘菜单选择“退出”结束程序。
- 建议在“设置 → 记录设置”中开启开机启动。
- 可暂停 5 分钟、1 小时、4 小时或 1 天，到时自动恢复，也可提前手动恢复。
- 需要保持程序运行才能记录；退出、休眠或暂停期间不补记。
- 想先体验界面，可在命令行运行 `WorkState.exe --demo`；演示模式使用独立虚构数据。
- 在“关于”中选择“检查更新”，下载完成后可“重启并更新”。检查优先使用 GitHub，连接失败时回退到 ghproxy；下载使用同一个源。更新保留数据、设置和开机启动状态。

## 数据

记录仅保存在本机，包含程序名和窗口标题，不上传用户活动数据。
仅用户主动检查和下载更新时访问更新服务。

新安装默认保存到 `%LOCALAPPDATA%/WorkState/data`，可从托盘打开数据目录。数据库长期保留，日志保留一个月。历史记录可在设置中清理或导出，单次导出最长一年。

旧版用户可在“设置 → 数据存储”中导入 `pcstate.db`。完成后请停用旧版开机自启，并从托盘退出旧版。

导出文件可能含有网页标题、文档名等个人信息，分享前请检查。
