# 数据管理

## 文件与保留期限

新安装默认使用 `%LOCALAPPDATA%/WorkState/data`，可从托盘菜单打开数据目录，也可用 `--data-dir PATH` 指定。

| 文件 | 用途 | 保留期限 |
| --- | --- | --- |
| `activity.sqlite3` | 活动记录、设置 | 永久保存，除非用户手动清理 |
| `activity.sqlite3-wal`、`activity.sqlite3-shm` | SQLite 运行时辅助文件 | 由 SQLite 管理 |
| `workstate.log`、`workstate.log.YYYY-MM-DD` | 运行诊断日志 | 一个自然月 |

程序不自动分割数据库、不自动归档 CSV，也不读取历史 CSV 作为报表数据。

备份前从托盘退出程序，再复制整个数据目录；不要在程序运行时只复制主数据库文件。恢复时也应先退出程序。

演示模式与正式数据分开。传入 `--demo --data-dir PATH` 时，演示数据写入 `PATH/demo`。

## 活跃时长统计粒度

采集和 CSV 导出始终保留原始分钟记录。在“设置 → 记录设置”选择统计粒度，只改变报表口径，不改写历史记录。

- **1 分钟**：每条活跃记录计一分钟，为默认方式。
- **5 分钟**：按热力图的五分钟边界划片，片内存在活动即计五分钟；没有活动的小片计零。按各程序在片内的实际活跃分钟比例分配时长，中间计算保留浮点精度，显示最多一位小数。
- 统计日仍遵循“一天起始时间”。富内容的细分单列门槛仍按每日实际活跃分钟判断，切换粒度不改变识别与单列规则。
- 热力图格子的颜色、提示和记录覆盖量保留实际分钟；图表统计、日活跃时长注记及饼图、柱状图采用所选口径。

设置旁的今日预览可在保存前比较两种口径，保存后报表生效。

## 清理历史记录

在“设置 → 数据存储”选择日期区间、某日期之前，或快捷选择三个月前、半年前、一年前。先预览记录数，再确认永久删除。

- 区间包含起止日期；“某日期之前”不包含指定当天。
- 日期按本机自然日 0:00 划分，不受报表的一天起始时间影响。
- 预览五分钟内有效，且只能确认一次。范围内记录数改变后需要重新预览。
- 成功后尝试压缩数据库；清理不会删除程序设置。

## 导出 CSV

在“设置 → 导出数据”选择区间，单次最长一个日历年，含起止日期，例如 `2024-01-01` 至 `2024-12-31`。导出和报表均按设置的统计日起始时间划分日期，图表查询不受一年限制。

CSV 为 UTF-8 BOM 编码，保留原始记录，包含以下字段：

| 列 | 含义 |
| --- | --- |
| `schema_version` | 导出格式版本，当前为 1 |
| `timestamp` | 带时区偏移的可读时间 |
| `minute` | Unix 分钟时间戳，用于标识同一分钟 |
| `active` | 1 为活跃，0 为闲置 |
| `process` | 原始进程名 |
| `title` | 原始窗口标题 |

窗口标题可能包含网页标题、文档名等个人信息，分享前请检查。

## 导入 PCState

选择旧版 `pcstate.db` 后，程序以只读快照预览日期范围、新增和重复记录数。确认后一次性导入，失败时整体回滚；相同分钟保留本版已有记录，不覆盖设置。

支持保留原始进程、标题的旧版本，也兼容仅保存旧名称或 `win_title` 的早期版本。缺失的原始信息无法恢复。预览十分钟内有效，取消或退出会释放临时快照。旧版在选择后新增的记录，需要再次导入。

完成后请停用旧版开机自启，并从托盘退出旧版。原数据库保留不变，可另行备份。

已有的 `PCState/data/activity.sqlite3` 与旧版 `pcstate.db` 不同：新 WorkState 目录尚无数据库时，程序会自动沿用已有的 `%LOCALAPPDATA%/PCState/data`。不会自动合并两个目录中同时存在的数据库。
